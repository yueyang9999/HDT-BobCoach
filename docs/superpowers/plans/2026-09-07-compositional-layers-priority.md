# 组合记忆/破局推理 — 分层优先级设计（价值·成本·追踪）

日期：2026-09-07
上游：`2026-09-07-compositional-reasoning-layer-LLD.md`（实现细节与动态审查 D1–D12）
用途：**按重要级分层 → 便于定位问题、核定每层投入性价比、逐层稳定可回退、全程可追踪**。
实施会话按本文件决定"做到哪一层"；每层独立门禁，低层不过则高层不启动。

## 〇、分层总览（自下而上，依赖方向严格）

```
L4 学习层(远期/可选)   value function + 深度规划 —— 承接解析模型给不出的联合动态
L3 动态增强(可选)      D7 自适应发散K(DPP) · D8 期权/流动性资产 · D12 成型率指标正式化
L2 模型细化(条件性)    D4 对手竞争/反制出口 · D3 爆买流动性 · D6 阶段目标 · D1 多通道可达 · D9 记忆动态+复盘归因
L1 骨架(必做核心)      P1 三桶 ceiling-gap · C-12 最小版: D2 升本视野耦合 · D5 血量时钟 · D10 幂等/预算
L0 数据与可复现基座    组合模板三源归一(45 真卡ID) · 确定性回归门禁 · 回放登记/真实状态语料
```

决策规则：**L0+L1 = 最小可行完整段（先证明/证伪"条件性破局"，工程安全）；L2 = 在 L1 证据上细化；
L3/L4 = 可选，视 L1/L2 缺口证据决定**。任何一层证据为负 → 该层及以上收窄或停（防沉没成本）。

## 一、逐层规格（每层：目标 / 内容 / 验收 / 成本估计 / 性价比）

### L0 — 数据与可复现基座（成本 ~0.5–1 天；性价比：极高，一切上层前提）
- 内容：
  1. `composition_templates.json` 三源归一**完成 45 套真实卡 ID**（中文23 经
     `guide_weight_reference.json` 取 officialCardId，英文22 经 comp_strategies；§八 勘误已点明）。
  2. 确定性回归门禁固化：`--diag-repro` 3 连跑一致 + 每局卡表指纹断言（脚本化，改动必跑）。
  3. 回放登记册已登记、真实 mid-game 状态语料可采样（L1 第三桶来源）。
- 验收：模板 45/45 非占位 + 覆盖校验过 + sha256 记录；diag-repro 输出贴进记录；语料桶 ≥N 状态。
- 追踪标识：文件 sha + `ISSUE_TRACKER` L0 项；回归日志 `runs/diag-*`。
- 出问题的定位法：模板/确定性/语料任何一项红 → **先查本层**（上层全部失效都先怀疑这里）。

### L1 — 骨架（成本 ~3–5 天；性价比：最高——一次判定"破局是真命题还是伪命题"）
- 内容：
  1. **P1 三桶 ceiling-gap**（LLD §九/§十）：全样本 / 崩盘-clock(D5) 子集 / 真实状态(D11) 子集，
     多 seed（≥3 seed × ≥20 决策点）；报告 `runs/ceiling-gap-*`。
  2. **C-12 最小版**（P2 子集）：
     - `CompositionState`：含资产维度（对子/三连进度，D8 最小）与阶段（D6 最小: Early 仅 shadow）。
     - `CeilingEstimator`：输入 `plannedTierHorizon`（D2，由现有升本曲线推）；缺数值→null 降置信。
     - `CompositionPlanner`：`mode: rescue|shadow`，触发 = **D5 clock**（血/期望伤 < 成型还需回合，
       血≤15 兜底）；**D10 幂等**：同回合状态指纹缓存，先规则后组合 early-exit。
  3. 工程安全：单测 + 代码审查（重入/双向验证留帧）+ 100% 回归 + legacy 零改动。
- 验收：M1（可达性预测 vs 引擎真值 ≤5pp）；M3（崩盘-clock 桶缺口 > 0 且 > 噪声）；M5 雏形
  （成型率双轨：全样本 vs 崩盘桶）；回归 100%。
- **Go/No-Go 判定点**：崩盘-clock 桶无显著缺口 → 条件性破局假设不成立 → 收敛到"只做 Shadow 记录"
  并停 L2；有缺口 → 进 L2。
- 追踪：`ISSUE_TRACKER` C-12 主项；每桶报告留存；预测 vs 真值残差文件（M1 持续监控）。

### L2 — 模型细化（条件性；成本 ~4–6 天；性价比：依赖 L1 证据，证据强才高）
- 内容（全部在 L1 接口上扩展，不改骨架）：
  - D4 contest（同引擎对手数可观测→V 惩罚）+ **反制出口路线**（领先成型→rescue 转 tech）。
  - D3 负担能力（金+可卖资产+在途经济）进入口与窗口；D1 多通道可达（发现/三连/法术/伙伴/饰品）；
    D6 阶段目标完整（TurnPhaseEngine 分派 Early/Mid/Late）；D9 `CompositionMemory`
    {seenAndPassed, ownedNow, ownedLost, opponentSeen} + 对局复盘归因（SAGA 模式）反哺。
- 验收：M2（路线排序 vs 回放体系胜率 Kendall τ ≥0.7）；归因与 V 系列一致；Shadow A/B
  （300 场景 + owner 门禁）后才考虑可见。
- 追踪：各 Dx 独立 ISSUE 子项 + 离线分析报告；归因案例库（标注 build/日期）。

### L3 — 动态增强（可选；成本 ~3–5 天；性价比：理论价值高，但须 L1/L2 缺口撑得起）
- 内容：D7 自适应发散宽度 K=f(不确定性,健康,阶段)（DPP/MMD，阈值触发）；D8 期权资产完整
  （对子=转型期权、三连奖励=定向高本）；D12 M5 成型率/成型回合正式纳入验收矩阵。
- 验收：M5 双侧（政策对照，条件化 mid/late）；K 自适应不劣于固定 K 的 Shadow 对照。

### L4 — 学习层（远期，独立预算；性价比：未知，按 L1–L3 证据立项）
- 内容：机制特征价值函数（rollout 标签）+ 束/深度规划，承接解析模型上限之外的联合动态
  （level×buy×comp）。对应 08-31 计划阶段2。数据边界：Shadow + legacy 兜底 + 跨赛季迁移测试。

## 二、性价比核定表（投入 vs 期望价值 vs 门禁）

| 层 | 成本(人日) | 期望价值 | 主要风险 | 继续投入的 Go 条件 |
|---|---|---|---|---|
| L0 | 0.5–1 | 一切前提, 消除"换会话考古/数据失忆" | 三源归一卡 ID 差异 | —（必做） |
| L1 | 3–5 | **判定条件性破局真伪 + 交付安全骨架** | 模拟器对手弱掩盖 gap | —（必做）；崩盘桶无缺口→停 L2 |
| L2 | 4–6 | 把 L1 缺口兑现为可测提升(Shadow) | 参数增多/过拟合 | L1 崩盘桶缺口显著 |
| L3 | 3–5 | 动态宽度/期权理论价值 | 复杂度 > 收益 | L1/L2 证据支撑 |
| L4 | 立项估 | 长期通用内核(跨赛季) | 数据边界/算力 | L1–L3 证据 + 真实数据可校准 |

> 核定口径：只保留"有 L1 证据支撑"的层；L0+L1 总成本约 0.5 周即可给出方向性结论，避免整包投入。

## 三、追踪与问题定位机制（每层可观测、可回退、可追责）

1. **每层独立门禁与产物命名**：`composition_templates.json(+sha)` → `runs/ceiling-gap-<seed>-<桶>.md`
   → `M1 残差/M3 缺口/M2 τ` 每轮存档 → `ISSUE_TRACKER`（L0 数据 / C-12 / Dx 子项）。
2. **问题定位顺序（出现异常先查哪层）**：
   结果不对 → 先 L0（确定性/模板/语料）→ 再 L1（预测 vs 真值残差 / 崩盘桶口径）→
   再 L2（参数/口径）→ 最后才怀疑引擎/规则（且须先跑回归确认 legacy 未动）。
3. **稳定性保障**：每层契约版本化（schema/sha）；legacy 零改动直到 L2 验收；每层可整层回退；
   确定性门禁任何改动必跑；记录回填（ITERATION_LEARNINGS/HANDOVER）为硬环节。
4. **投入核定入口**：本文件 §二 表 + Go 条件；预算只批"当前层"，后续按证据逐层放行。

## 四、实施顺序建议（给实现会话）

`L0 → L1（含 Go/No-Go 判定）→ 汇报 → 依证据决定 L2/L3/L4`。L0+L1 完成即交付
"条件性破局证据包 + 安全骨架"，之后每层都是独立可批复的增量。
