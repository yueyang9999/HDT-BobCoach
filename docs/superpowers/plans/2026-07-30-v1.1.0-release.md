# BobCoach v1.1.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish the validated status-strip customization and HDT 1.54 compatibility work as BobCoach `v1.1.0`, with synchronized documentation, privacy-cleaned screenshots, deterministic offline assets, and a public GitHub Release.

**Architecture:** Keep the existing single-source release identity in `release_identity.json` and propagate it through the current build and packaging scripts. Treat the Markdown/HTML installation guides and package allowlists as explicit release contracts. Build one verified ZIP outside Git, then reuse the exact same bytes for GitHub and the local Quark upload directory.

**Tech Stack:** C# 7.3 / .NET Framework 4.7.2, WPF, PowerShell 5.1, Node.js contract tests, GitHub CLI, Pillow for privacy-cleaned screenshot derivatives.

## Global Constraints

- Package version is exactly `1.1.0`; assembly version is exactly `1.1.0.0`; Git tag is exactly `v1.1.0`.
- HDT baseline remains exactly `1.54.0.7376`.
- Raw screenshots stay unchanged and outside Git; committed derivatives are at most 1600 px on the longest edge and target at most 500 KiB each.
- The repository contains no generated ZIP, DLL, logs, validation evidence, user data, credentials, or personal paths.
- Release assets are exactly `BobCoach-1.1.0-win-x64.zip` and `BobCoach-1.1.0-win-x64.zip.sha256`.
- No test bypasses, warning suppressions, public-history rewrites, force pushes, or deletion of prior releases.
