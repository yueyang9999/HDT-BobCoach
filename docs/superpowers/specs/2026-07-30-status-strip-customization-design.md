# BobCoach 状态提示面板字号与拖动设计

日期：2026-07-30  
状态：用户已批准设计，待规格复核

## 1. 问题与目标

BobCoach 当前在炉石客户区左上角绘制回合、节奏和操作建议。该状态提示由 `OverlayRenderer.ShowStatusStrip()` 创建，字号固定为 12-13 WPF DIP，位置固定为 1920x1080 基准坐标 `(8, 105)`。实战中字体偏小，且玩家无法根据分辨率、视力和其他 HDT 浮窗的位置调整它。

本次改动提供以下能力：

- 在 HDT 的 BobCoach 插件菜单中打开状态面板设置。
- 将状态面板整体字号调为 `12-28`，默认 `16`。
- 临时解锁后，按住面板任意位置拖动。
- 持久化字号和位置；每次插件启动时默认锁定。
- 防止面板被拖出炉石客户区，并提供恢复默认。
- 让现有 F10 校准模式中的 `1 = Status` 真正能够调整状态面板位置。

## 2. 不在本次范围内

- 不把状态面板改成独立 WPF Overlay Window。
- 不改变提示内容、决策逻辑、颜色语义或战斗阶段显隐规则。
- 不分别设置标题、正文或每一行的字号。
- 不增加字体、透明度、背景色或面板宽度设置。
- 不改变 `OnButtonPress()` 的 Power.log 配置助手用途。
- 不增加网络依赖或上传任何玩家数据。

## 3. 已确认的产品决策

| 项目 | 决策 |
| --- | --- |
| 设置入口 | HDT 的 BobCoach 插件菜单 |
| 字号 | 滑块，`12-28`，默认 `16`，整数步进 |
| 缩放范围 | 标题、正文、行高、内边距和最大宽度整体同比例缩放 |
| 拖动方式 | 解锁后按住面板任意位置拖动 |
| 持久化 | 保存字号和位置；不保存解锁状态 |
| 启动状态 | 每次插件启动默认锁定 |
| 恢复默认 | 同时恢复位置 `(8, 105)` 和字号 `16` |
| 越界处理 | 面板始终限制在当前炉石客户区内 |

## 4. 交互设计

### 4.1 设置入口

`BobCoachPlugin.MenuItem` 不再返回 `null`，而是提供“Bob教练设置”入口。入口打开一个轻量、非模态的状态面板设置窗口，使玩家可以保留设置窗口并同时在炉石画面中拖动面板。

设置窗口只包含三个控件：

1. “解锁状态面板”复选框。
2. “字体大小”滑块和当前整数值。
3. “恢复默认”按钮。

字号在拖动滑块时实时预览，在滑块释放时保存。点击恢复默认后立即刷新面板并保存。关闭设置窗口时自动锁定面板；重新打开窗口会反映当前字号和锁定状态。

### 4.2 锁定与拖动

锁定时，状态面板保持现有的鼠标穿透行为，不拦截炉石操作。

解锁时，仅状态面板自身参与命中测试，鼠标移入显示移动光标。按下鼠标左键后捕获鼠标并开始拖动；移动期间实时更新显示位置；释放鼠标、丢失捕获或设置窗口关闭时结束拖动。有效拖动完成后保存位置。

解锁态使用轻量边框作为状态反馈，不增加操作说明文字或常驻拖动把手。锁定后边框和移动光标消失。

为避免状态刷新中断拖动，渲染器保留一个稳定的状态面板根元素，只更新其行内容和样式。清空覆盖层、进入战斗或插件卸载时，应释放鼠标捕获并移除事件处理。

### 4.3 位置边界

面板完成测量后，根据其实际宽高限制左上角坐标：

- `x` 位于 `0` 到 `canvasWidth - panelWidth`。
- `y` 位于 `0` 到 `canvasHeight - panelHeight`。
- 若面板尺寸超过客户区，对应轴使用 `0`，并限制文本最大宽度以保证内容仍可见。

拖动、载入旧配置、字号变化和客户区尺寸变化时都重新执行边界限制。因显示器或分辨率变化导致已保存坐标失效时，保存修正后的可见坐标，避免每次启动重复越界。

## 5. 配置与兼容性

`LayoutConfig` 新增：

- `StatusOffsetX`：默认 `8`，使用当前校准坐标系中的水平位置。
- `StatusOffsetY`：默认 `105`，使用当前校准坐标系中的垂直位置。
- `StatusFontSize`：默认 `16`，有效范围 `12-28`。

解锁状态只存在于本次插件进程内，不写入 `ui_config.json`。

位置继续遵循 `CalibrationWidth`、`CalibrationHeight` 和现有 `ScaleX/ScaleY` 规则。校准尺寸变化时，`StatusOffsetX/Y` 与其他像素位置一起重基准；字号是 WPF DIP，不随校准尺寸重基准，以保证玩家选择的可读大小稳定。

配置版本升级时必须显式迁移：

- v10 配置保留全部现有字段，只补入新的状态面板默认值。
- v9 配置先执行现有商店偏移迁移，再补入状态面板默认值。
- 非有限数值、越界字号或无法解析的新增字段回退到默认值，不影响其他有效配置。
- 不得因新增字段重置玩家已有的商店、战场、手牌或推荐面板校准值。

## 6. 组件边界与数据流

### 6.1 `LayoutConfig`

负责持久化、默认值、版本迁移和基础数值规范化。它不保存临时解锁状态，也不处理 WPF 鼠标事件。

### 6.2 `GameLayoutCalculator`

`GetStatusStripPosition()` 从 `LayoutConfig.StatusOffsetX/Y` 计算当前 OverlayCanvas 坐标，不再返回写死的位置。该类继续只负责坐标换算，不负责测量面板或处理拖动。

### 6.3 状态面板布局策略

新增一个不依赖 HDT 运行时的纯布局策略，负责：

- 将字号限制到 `12-28`。
- 以当前主要提示行的 `13` DIP 为基准，计算 `StatusFontSize / 13` 的整体排版比例。
- 根据画布和面板尺寸限制显示位置。

该策略使边界和字号行为可通过独立行为测试验证，避免只能依赖实机鼠标测试。

### 6.4 `OverlayRenderer`

负责创建和复用状态面板根元素、按配置生成排版、切换命中测试、处理拖动事件，并在配置变化时刷新。状态文本仍由现有 `ShowStatusStrip(StatusInfo)` 数据流驱动。

`StatusFontSize` 直接表示主要提示行的字号，因此默认值 `16` 会把当前 13 DIP 的主要提示行放大到 16 DIP。当前 12 DIP 的次要行保留 `12/13` 的相对比例；行高、内边距和 260/280 最大宽度统一乘以 `StatusFontSize / 13`。颜色、字重和各行条件保持不变。

### 6.5 BobCoach 设置窗口

负责展示控件、维护本次运行的解锁状态并将用户变更交给渲染器。设置窗口不直接操作 OverlayCanvas 子元素，也不拥有第二套配置对象。

数据流如下：

1. 插件加载 `LayoutConfig`，渲染器以锁定状态初始化。
2. 设置窗口改变字号，更新共享配置并请求状态面板刷新。
3. 解锁开关只改变运行时交互状态。
4. 拖动完成后，渲染器把客户区坐标转换为配置坐标并保存。
5. 重启插件后读取已保存字号和位置，但解锁状态恢复为关闭。

## 7. F10 校准兼容

F10 校准模式保留，且补全现有空实现：

- `1` 选择 `Status` 后，方向键修改 `StatusOffsetX/Y`。
- `R` 只恢复状态面板默认位置，不改变玩家设置的字号。
- `S` 延续现有保存行为。
- 设置窗口中的“恢复默认”同时恢复位置和字号。

F10 与设置窗口写入同一份 `LayoutConfig`，不得产生第二套位置字段。

## 8. 异常与生命周期处理

- 配置文件不存在或新增字段无效时使用默认值，插件继续加载。
- 保存失败时保持本次运行内的显示效果并写入 BobCoach 日志，不让异常进入 HDT UI 线程。
- 状态面板不可见、OverlayCanvas 尚未就绪或客户区尺寸无效时，不尝试拖动或保存错误坐标。
- 插件卸载、进入战斗、清空 UI 或关闭设置窗口时释放鼠标捕获并恢复锁定。
- 重复打开设置入口时激活已有窗口，不创建多个窗口或多套事件订阅。

## 9. 验证与验收标准

### 9.1 自动化测试

- `LayoutConfig` 默认字号和位置正确。
- v9、v10 配置迁移后保留既有校准字段，并获得新默认值。
- 小于 `12`、大于 `28`、`NaN` 和无限字号被规范化。
- 不同画布和面板尺寸下的位置限制正确，包括面板大于画布的边界。
- `GameLayoutCalculator.GetStatusStripPosition()` 使用配置位置并正确缩放。
- F10 `Status` 的方向键和重置行为更新正确字段。
- 源码契约测试确认 `MenuItem` 不再为 `null`、`OnButtonPress()` 仍保留 Power.log 配置助手。
- 运行仓库 `docs/maintainer/BUILD.md` 要求的完整构建、行为测试、包检查、敏感文件扫描与 `git diff --check`。

### 9.2 实机验收

在 HDT 1.54 和炉石酒馆战棋招募阶段验证：

- 默认显示字号为 `16`，所有文字行、间距和背景宽度同比例变化且不重叠。
- 字号从 `12` 调到 `28` 时实时预览，释放后重启 HDT 仍保留。
- 解锁后可从面板任意位置拖动，拖动期间不会因状态刷新跳回或中断。
- 锁定后点击面板区域不会阻挡炉石操作。
- 面板无法拖出客户区；改变窗口尺寸、分辨率和 DPI 后仍可见。
- 关闭设置窗口和重启 HDT 后均恢复锁定。
- “恢复默认”恢复 `(8, 105)` 和 `16`。
- F10 的 `1 = Status` 能移动并保存同一位置。
- 进入战斗时状态面板仍按现有规则隐藏，返回招募阶段后按保存位置出现。
