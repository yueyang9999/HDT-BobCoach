# Bob Coach 功能展示

BobCoach 会根据当前对局给出醒目的操作建议，帮助你在回合时间里更快做决定。它只提供建议，不会自动操作游戏，最终选择始终由玩家完成。

[离线打开 HTML 功能展示页](FEATURES.html) · [查看安装教程](INSTALL.md)

## 状态提示面板

从 `选项 > 插件 > Bob教练设置` 打开状态面板设置。

![从插件页面进入 Bob教练状态面板设置](images/features/status-strip-settings-entry.jpg)

先调节 `字体大小`；需要调整位置时启用 `解锁状态面板`，只在 `Hearthstone 窗口` 内拖动提示面板。

![状态面板的字体大小和解锁状态面板控件](images/features/status-strip-controls.jpg)

完成后禁用 `解锁状态面板` 或关闭设置，面板会恢复 `鼠标穿透`。必要时使用 `恢复默认` 重置位置和字号。

![调整后的状态提示面板显示效果](images/features/status-strip-result.jpg)

“恢复默认”会同时恢复默认位置和 `16` 号字。F10 校准模式中的 `1 = Status` 仍可调整同一面板的位置，并保留玩家选择的字号。

## 购买建议

商店里同时出现多个随从时，BobCoach 会标出当前阵容更值得购买的目标，减少反复比较的时间。

![BobCoach 在酒馆商店中标出购买建议](images/features/feature-01-buy.jpg)

## 升本建议

当这一回合适合升级酒馆等级时，BobCoach 会在升本按钮附近给出提示，帮助你权衡战力和成长节奏。

![BobCoach 提示当前回合可以升级酒馆等级](images/features/feature-02-upgrade.jpg)

## 技能提示

英雄技能容易被忙碌操作忽略时，BobCoach 会提醒更合适的使用时机。

![BobCoach 提醒玩家使用英雄技能](images/features/feature-03-hero-power.jpg)

## 饰品推荐

面对多件饰品时，BobCoach 会结合当前对局标出更合适的选择，玩家仍可查看全部效果后自行决定。

![BobCoach 在饰品选择界面给出推荐](images/features/feature-04-trinket.jpg)

## 发现选择

遇到三选一等发现界面时，BobCoach 会辅助比较候选项，让关键选择更直观。

![BobCoach 在发现界面辅助比较三个选项](images/features/feature-05-discover.jpg)

截图中的玩家名称和分数已经过隐私处理。游戏画面与名称归各自权利人所有，Bob Coach 是独立社区项目。
