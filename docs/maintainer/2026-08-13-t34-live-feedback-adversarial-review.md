# T34 Live Feedback Adversarial Review

Date: 2026-08-13

## Conclusion

The fixes pass deterministic engineering gates and address the reproduced live-data failure paths. They do not establish strategy-quality improvement or effect acceptance.

## Reviewed Findings

### Faelin Discovery

- The parser only emits passive-choice batches for `BG22_HERO_201p`.
- Active batches now enter the authoritative discover batch and panel state.
- Completion clears only the matching discover batch and panel state.
- Ordinary discover, dark gift, timewarp, and trinket pipelines remain separate.

### Mainline Direction

- Core-tribe evidence is tracked separately from ordinary `CardCount`.
- Any direction with core evidence is resolved before ordinary tribe counts.
- Hard comp lock remains the strongest override.
- The original Quilboar-vs-Demon replay failure is covered by the contract.

### Full Board Transition

- Matching-tribe buy candidates prioritize mainline core and triple evidence.
- A full board returns a sell action only when a generated sell action exists.
- Sell candidates exclude golden, recently bought, protected, engine, and mainline core cards.
- The shop replacement must be stronger than the sold minion.
- This prevents a low-tier matching card from triggering a destructive sell.

### BG36_880 Methodical Madness

- Hand spells no longer inherit the shop purchase cost.
- Hand spells are not frozen solely because attack and health are zero.
- `UseSpell` is generated at zero cost.
- The visible target is restricted to friendly Demons.
- The unconditional early return was removed.
- The safe fallback requires at least two non-spell Tavern minions.
- Core/triple shop cards, affordable buys, affordable non-lethal leveling, and freeze-worthy shops suppress the fallback.

## Residual Engineering Risks

- The `BG36_880` target picks a Demon by stats and tier, not full card-effect semantics. Future work should use versioned card effect data when available.
- Mainline core cards that appear in multiple guide catalogs can still add evidence to multiple tribes. The current fix handles the reproduced single-core-vs-ordinary-count case without changing cross-guide weighting.
- Full-board sell-to-buy is one-step visible guidance. The two-step search and visualizer still decide how the subsequent shop target is highlighted.
- The T34 replay was generated by the old DLL, so it proves the reproduced failure only. It cannot prove that the new deployment improves the live decision.
